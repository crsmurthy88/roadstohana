## Transition approaches

**Greenfield — start clean.** New implementation on standard. The right call when the legacy design
is itself the problem, when the business model has changed, or when reporting and regulatory
demands have outgrown what the old configuration can carry.

**Brownfield — convert in place.** System conversion that preserves history and configuration.
Faster and cheaper where the existing design still holds, but it carries every old compromise
forward, so the assessment matters more than the migration.

**Hybrid — selective transition.** Convert what works, rebuild what doesn't. Usually the honest
answer for large landscapes: a clean chart of accounts and new ledger design alongside retained
transactional history and proven process areas.
